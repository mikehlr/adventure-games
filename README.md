# Τα παιχνίδια — retro adventures

25 εκδόσεις παιχνιδιών (v2 πλάγια κύλιση · 2.5D · VGA · HD) και η σελίδα επιλογής `index.html`.
Κάθε παιχνίδι είναι ένα αυτόνομο αρχείο HTML — δεν χρειάζεται server ή εγκατάσταση.

## Παίξε τοπικά
Αποσυμπίεσε το zip και άνοιξε το `index.html` σε Chrome, Safari, Edge ή Firefox.

## Δημοσίευση στο GitHub Pages
1. Φτιάξε νέο δημόσιο repository στο GitHub (π.χ. `paixnidia`).
2. **Add file → Upload files** και σύρε όλο το περιεχόμενο του φακέλου `paixnidia/` (`index.html`, `games/`, `README.md`, `.nojekyll`). **Commit changes**.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch: `main`, φάκελος `/ (root)` → **Save**.
4. Σε 1–2 λεπτά η σελίδα είναι στο `https://<το-όνομά-σου>.github.io/paixnidia/`.

Σημειώσεις: οι αποθηκεύσεις (save slots) μένουν στον browser κάθε παίκτη (localStorage). Οι γραμματοσειρές φορτώνονται από Google Fonts· χωρίς internet χρησιμοποιούνται εναλλακτικές.
